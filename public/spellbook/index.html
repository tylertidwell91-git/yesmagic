Commander Deck Builder

Choose a commander-eligible legendary creature (or planeswalker that can be your commander). Suggestions come from the same card catalog as Add cards. Pick deck colors (a subset of your commander’s identity) to drive the catalog search and basic land mix. Optionally set a max deck value in USD so the 100-card list stays within budget (commander included). The tool builds your mana base first (nonbasics from the catalog, then basics split across those colors), then fills out spells using the same scoring signals as the Deck advisor, biased by objectives inferred from your commander (tribal types, keywords, spellslinger vs creatures, tokens, graveyard, artifacts, enchantments, etc.), while skipping library tutors that name basic land types or subtypes your list does not run (snow / Wastes handled the same way).

Pick one suggestion to load the exact printing.
